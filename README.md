🤖 AI 協作紀錄
1. AI 協助的部分
網站整體架構與風格設計：根據個人作品集與課堂作業規格，AI 建議採用戰術警戒黃（Tactical Yellow）搭配深灰黑底之「扁平戰術風格（Tactical Flat Graphic Design System）」，確立單頁式科技感流暢佈局。
HTML 結構與 CSS 變數系統：由 AI 協助編寫語意化標籤，並運用 CSS 自訂變數（Custom Properties）統一管理全站色彩、字級、間距與邊框科技裁角（clip-path）。
微互動 JavaScript 開發：
開發「委託人揮鞭催畫」互動系統，每次點擊提高作品完成度（0%～100%），並動態隨機彈出 2D 平面、逐幀動畫、3D 建模等進度標籤與立繪動畫反饋。
實作作品彈窗播放器（Modal），支援點擊即可在不跳轉頁面的情況下播放 MP4/MOV 影片。
實作主視覺卡片 3D 視差傾斜特效（MouseMove Tilt Effect）。
實作全站即時主題色系切換（警戒黃、電競青、極限紅等）。

互動機制與文案優化：

跨裝置測試與除錯：
實際於 Chrome 等瀏覽器測試桌面與手機版直向排版，確保影片彈窗開啟/關閉無阻、圖片不失真、音效播放正常。
3. 學習收穫
掌握 CSS 變數與設計系統思維：深刻體會 CSS Variables 在大型網頁維護中的便利性，改動一組主題變數即可瞬時刷新全站氛圍。
掌握多媒體整合與彈窗控制技術：學習透過原生 JavaScript 事件監聽動態替換 <video> 來源並控制播放/暫停，無需額外依賴大型前端框架。
理解幾何裁角與科技感排版技巧：學會運用 clip-path: polygon(...) 創造不規則戰術幾何切角，擺脫傳統呆板的圓角方塊外觀。
體會人機協作的真實分工：AI 擅長快速建構結構框架與動畫原型，而真實內容的取捨、原創作品的品質把關、個人真實態度的傳達，必須由創作者本人親自決策。
🔧 如何替換作品影音資源

本專案所有圖片與影片皆嚴格規範存放於 im/ 目錄，替換方式如下：

替換平面作品：
將新圖檔放入 im/ 目錄中。
在 index.html 的 <!-- SECTION 5: PORTFOLIO WORKS --> 區塊找到對應作品卡片，修改 src="im/您的檔案名稱.png" 及 alt 說明即可。
替換動畫影片：
將 MP4 或 MOV 格式影片放置於 im/ 目錄。
在作品對應按鈕或視訊標籤中修改 data-video="im/您的影片名稱.mp4"。
替換立繪或圖標：
替換 im/IMG_3087.PNG（持筆創作者立繪）或 im/513BD1EF-6A8A-4497-ADDA-7C16B2AD3B7D.gif（小人寫作圖標）。
